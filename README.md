# llm-camd

A simple crypto-misuse-detector that combines state-of-the-art rule sets with CoT prompting to support multiple languages.

## Rule sets
### Python
Uses rule set from "From Hallucination to Precision"

### Java
Also from "From Hallucination to Precision"

### Go
Uses rule sets from CryptoGo, Gopher (CryDict), and "Evaluating Cryptographic API Misuse Detectors for Go"

### JavaScript
Uses rule set from JScamd

### General
Uses taxonomies from MASC and CryMisTa
